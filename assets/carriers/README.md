# Vietnamese carrier logo sources

These marks are owned by their respective trademark holders and are used for identification only. APN Atlas VN is not endorsed by any operator. **Trademark/logo assets are not licensed under the project's MIT code license.**

The optimized PNGs are checked in under `assets/carriers/`; `npm run assets:carriers` refreshes them from the recorded sources. Builds only copy the local files, and the app never fetches a logo at runtime. When an asset is missing, the UI falls back to the existing monogram rather than showing an unrelated operator's logo.
